Editor Features

  • Autocomplete: Press Ctrl+Space for tag/property hints.
  • Image Paste: Copy any image and press Ctrl+V in the editor to insert as Base64.
  • Bracket Scope: Click on any ( [ { to see a colored line in the left gutter showing the full block range.
  • Change Highlights: Edited text flashes green briefly so you can see exactly what changed.
  • Code Folding: Click the arrows in the gutter to collapse blocks.
